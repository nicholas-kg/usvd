# K18: Υλοποίηση Συστημάτων Βάσεων Δεδομένων

**Χειμερινό Εξάμηνο 2026 — Άσκηση 1: Διαχείριση Εγγραφών με Χρήση Μπλοκ σε Αρχείο Σωρού**

Η άσκηση ζητά την υλοποίηση ενός συνόλου συναρτήσεων (με πρόθεμα `HP_`) που
διαχειρίζονται αρχεία σωρού (heap files). Η υλοποίηση γίνεται **υποχρεωτικά** πάνω
από το επίπεδο διαχείρισης μπλοκ (`BF`), το οποίο δίνεται έτοιμο ως βιβλιοθήκη.

## Τι σας δίνεται

- `lib/libbf.so` και `include/bf.h` — το επίπεδο διαχείρισης μπλοκ
- `include/record.h` και `src/record.c` — η δομή `Record` και οι βοηθητικές
  `randomRecord`, `printRecord`
- `include/block_records.h` και `src/block_records.c` — η αντιγραφή εγγραφών
  σε/από ένα μπλοκ (`blockSetRecord`, `blockGetRecord`, `RECORDS_PER_BLOCK`)
- `examples/bf_main.c` — παράδειγμα χρήσης της βιβλιοθήκης `BF`
- `inputs/records.txt` — δείγμα αρχείου εισόδου
- `Makefile`

## Τι πρέπει να υλοποιήσετε

- `include/hp_file.h` — τη δομή `HP_info` (τα πρωτότυπα δίνονται έτοιμα)
- `src/hp_file.c` — τις 7 συναρτήσεις `HP_` στα σημεία που σημειώνονται με `TODO`
- `src/myheap.c` — τον driver: ανάγνωση του αρχείου εισόδου και κλήσεις των
  συναρτήσεων `HP_`

Προσέξτε ότι η `HP_info` **δεν** περνά ως παράμετρος στις συναρτήσεις του API.
Επομένως το επίπεδο `HP_` πρέπει να κρατάει μόνο του την κατάσταση που
χρειάζεται για κάθε ανοιχτό αρχείο.

## Δομή του project

- `include/` — τα αρχεία κεφαλίδας
- `src/` — η υλοποίηση και ο driver
- `examples/` — παράδειγμα χρήσης της libbf 
- `lib/` — η δοσμένη βιβλιοθήκη επιπέδου μπλοκ
- `inputs/` — τα αρχεία εισόδου
- `build/` — τα object files της μεταγλώττισης
- `bin/` — τα εκτελέσιμα
- `DBs/` — τα αρχεία βάσης που δημιουργούνται κατά την εκτέλεση

Οι κατάλογοι `build/`, `bin/` και `DBs/` δημιουργούνται αυτόματα από το `Makefile`,
εφόσον δεν υπάρχουν.

## Μεταγλώττιση

Για να μεταγλωττίσετε και τα δύο εκτελέσιμα:

```bash
make
```

Για ένα μόνο εκτελέσιμο:

```bash
make myheap    # δημιουργεί το ./bin/myheap
make bf        # δημιουργεί το ./bin/bf_main
```

## Εκτέλεση

Οι εντολές εκτελούνται **από τη ρίζα του project**, καθώς η βιβλιοθήκη
(`lib/libbf.so`) και τα αρχεία βάσης (`DBs/`) εντοπίζονται με relative paths:

```bash
./bin/myheap -i inputs/records.txt
./bin/bf_main
```

## Μορφή του αρχείου εισόδου

Κάθε γραμμή περιέχει μία εγγραφή, με τα πεδία χωρισμένα με κενά και στη σειρά
που έχουν στη δομή `Record`:

```
id firstname lastname postcode city
151 Dimitra Stasinou 12376 Ioannina
```

Το αρχείο σωρού δεν έχει πρωτεύον κλειδί, οπότε μπορούν να υπάρχουν
περισσότερες από μία εγγραφές με το ίδιο `id`.

## Καθαρισμός

```bash
make clean
```

Διαγράφονται τα εκτελέσιμα από το `bin/`, τα object files από το `build/` και τα
αρχεία βάσης από το `DBs/`. Οι ίδιοι οι κατάλογοι διατηρούνται.
