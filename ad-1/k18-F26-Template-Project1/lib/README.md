
In this directory there are 2 version of the libbf.so

1) libbf.so : this is the version of the library created 
		by Ubuntu-GLIBC-2.31-0ubuntu9.18
		on the linuxXY.di.uoa.gr


2) Ubu24.04-libbf.so  : this version has been generated with 
		Ubuntu-GLIBC-2.39-0ubuntu8.9  (more recent
		version of glibc for Ubuntu 24.04).
		@
		--> if you decide to use this lib (on an Ubuntu 24.04 insta) 
		    you have to rename Ubu24.04-libbf.so as libbf.so
		    to proceed with the compilation of your program.
